# Family 5 V1
Bản PWA Android đầu tiên: Trang chủ, lịch, công việc, 5 thành viên, cài đặt.
## Cách dùng nhanh trên Android
1. Giải nén thư mục lên một dịch vụ web có HTTPS (ví dụ GitHub Pages, Netlify hoặc máy chủ riêng).
2. Mở địa chỉ bằng Chrome Android.
3. Chọn menu ⋮ -> "Thêm vào màn hình chính" / "Cài đặt ứng dụng".
4. App lưu dữ liệu lịch và công việc trên thiết bị bằng localStorage.
## Lưu ý
Đây là V1 chạy thật để dùng thử trong 1 ngày. Chưa có đồng bộ giữa 5 điện thoại, đăng nhập và thông báo đẩy. Các phần này sẽ làm ở V2.
